# THE WORLD TODAY — Saturday 21 November 2026

A one-image newspaper front page summing up the world news of
Saturday 21 November 2026: one lead story, six grid stories, one
science strip, and six numbered In Brief items — fourteen stories
in all, each with its own small flat illustration drawn from
shapes, not photographs.

The page is generated by a single self-contained Python program
that uses only the standard library. It needs no network access
and no installed packages, and it always produces the same PNG
bytes for the same code.

## Run it locally

```sh
python3 main.py
```

By default the program writes to `$MAKEFUN_OUTPUT_DIR` (a directory,
where it creates `entry.png`, or a full `.png` path), falling back
to `/output/entry.png` when the variable is not set. To write
somewhere else for a local test, pass a path directly:

```sh
python3 main.py /tmp/entry.png
```

The output is a 1024×1024 PNG.

## What is on the page

- **Lead:** Missiles fall on Poland after an overnight Russian
  barrage on Ukraine.
- **Grid:** US stocks slide into correction; the White House press
  conference on the trilateral summit; tankers hit in the Strait
  of Hormuz; climate talks run over in Antalya; marches across
  Europe; the FBI database reportedly hacked (worded as
  unconfirmed, as the reporting stands).
- **Strip:** Mosquitoes bred to fight dengue in Brazil.
- **In Brief:** Bitcoin, Spain's bank tax, the Peru quake, a
  proposed card-rate cap, Kryvyi Rih, and the Basra power fire.

The date appears three times: the top bar, the red date ribbon,
and the footer.
